# Student Record Management System

A mini project for **CSD0111: Project Studio-I** (July-December 2026), built with HTML, CSS and JavaScript.

It stores student details and marks, and calculates total, percentage and grade automatically.

## Features

- Add, edit and delete student records
- Live search by name or roll number
- Form validation (roll number, name, email, phone, marks)
- Automatic total (out of 300), percentage and grade
- Dashboard with total students, average percentage, topper and failed count
- Data saved in the browser (localStorage)
- Responsive layout for mobile screens
- 20 sample records loaded on first run
